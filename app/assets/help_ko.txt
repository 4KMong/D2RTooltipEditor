# 편집기 개요

- 이 편집기는 D2R 툴팁용 `ÿcX` 색상코드가 섞인 txt 문서를 읽고 고치기 위한 도구입니다.
- 기본 작업은 **편집창**에서 합니다. 편집창은 실제 툴팁 문장을 보기 쉽게 보여주는 메인 영역입니다.
- **코드창**은 색상코드, 특수문자, 줄바꿈 상태를 확인하는 참고용 영역입니다.
- 코드창에서도 직접 편집할 수 있지만, 처음 사용하는 경우에는 편집창 기준으로 작업하는 편이 안전합니다.
- 레이아웃과 편집창/코드창 비율은 작업 방식에 맞게 바꿀 수 있습니다.

# 시작 로딩 화면

- 프로그램을 실행하면 메인 창보다 먼저 로딩 화면이 표시됩니다.
- 로딩 화면은 최소 3초 동안 유지되며, 메인 화면 초기화가 끝난 뒤 닫힙니다.
- 로딩 화면은 다른 창 위에 표시되지만 다른 프로그램의 포커스나 마우스 입력을 빼앗지 않습니다.

# 기본 작업 흐름

- txt 파일을 열거나 프로그램 창으로 드래그앤드롭합니다.
- 편집창에서 문장을 수정합니다.
- 필요한 글자를 선택한 뒤 색상칩이나 단축키로 색상을 적용합니다.
- 코드창에서 `ÿcX` 색상코드와 특수문자 상태를 확인합니다.
- 저장 전 상태표시줄과 경고창을 확인한 뒤 저장합니다.

# 파일 열기, 저장, 문서 탭

- 기본 지원 형식은 txt입니다.
- 여러 txt 문서를 탭으로 열어 동시에 편집할 수 있습니다.
- 여러 파일을 한꺼번에 드래그앤드롭하면 txt 파일만 파일명 순으로 열고, 함께 섞인 비-txt 파일은 무시합니다.
- 환경설정 > 일반의 **Windows 쉘 메뉴**는 기본적으로 켜져 있으며 txt 파일 우클릭 메뉴에 **D2R 툴팁편집기로 열기**를 추가하고 프로그램 아이콘을 사용합니다.
- 프로그램이 이미 실행 중이어도 쉘 메뉴로 선택한 txt는 새 창을 만들지 않고 기존 인스턴스에서 엽니다. Windows 11에서는 일반 registry shell 메뉴 특성상 **더 많은 옵션 표시** 아래에 보일 수 있습니다.
- [Ctrl]+[N]: 새 파일
- [Ctrl]+[O]: 열기
- [Ctrl]+[S]: 저장
- [Ctrl]+[Shift]+[S]: 다른 이름으로 저장
- [Ctrl]+[W]: 현재 문서 닫기
- [Ctrl]+[PageDown]/[PageUp]: 다음/이전 문서 탭으로 이동
- 저장할 때는 중복되거나 불필요한 색상코드를 보수적으로 정리합니다.
- 줄바꿈, 공백, 탭 구현 결과처럼 레이아웃에 영향을 주는 문자는 임의로 정리하지 않습니다.

# 시스템 트레이와 종료

- 환경설정의 **시스템 트레이 사용 (닫기 시 트레이로 보냄)**은 기본적으로 켜져 있습니다.
- 이 옵션이 켜져 있으면 프로그램 실행 중 트레이 아이콘이 유지되며, 창의 닫기 버튼을 누르면 프로그램을 종료하지 않고 트레이로 숨깁니다.
- 옵션이 꺼져 있으면 창이 보이는 동안 트레이 아이콘을 표시하지 않고, 닫기 버튼을 누르면 저장 확인 후 프로그램을 종료합니다.
- 트레이 아이콘을 더블클릭하면 숨겨진 창을 다시 표시합니다.
- 트레이 아이콘을 오른쪽 클릭하면 **환경설정**과 **종료** 메뉴가 나타납니다.
- 파일 메뉴의 **종료**는 닫기 버튼과 다릅니다. **종료**, **취소**, **트레이로 최소화** 중 하나를 선택할 수 있습니다.
- 파일 메뉴에서 선택한 **종료**와 창이 보이는 상태에서 트레이 메뉴의 **종료**는 기존 저장 확인 절차를 거쳐 프로그램을 완전히 종료합니다.
- 트레이에 숨겨져 있거나 최소화된 상태에서 트레이 메뉴의 **종료**를 누르면 창을 다시 띄우거나 애니메이션을 재생하지 않고 즉시 종료합니다.
- 일반 창과 최대화 창 모두 트레이로 숨길 때 오른쪽 아래 방향으로 이동하며 사라지고, 복귀할 때는 반대 방향으로 나타납니다. 최대화 창은 이동 중에도 크기와 최대화 상태를 유지합니다.
- 프로그램이 이미 실행 중일 때 실행 파일을 다시 실행하면 새 창을 만들지 않고 기존 창을 복귀시킵니다.
- 프로그램을 완전히 종료한 뒤 다시 실행하면 항상 창이 보이는 상태로 시작합니다. 처음부터 트레이에 숨겨서 시작하지 않습니다.

# 표시 설정 저장

- 환경설정에서 표시 설정 저장을 켜면 글꼴, 글자 크기, 줄 간격, 줄 맞춤 상태가 txt 파일 끝의 TTE 표시 설정 블록에 저장됩니다.
- 표시 설정 블록이 들어 있는 문서는 다음에 열 때 해당 표시 상태를 복원합니다.
- 표시 설정은 편집기에서 보기 좋게 작업하기 위한 정보이며, 툴팁 문장 자체와는 구분됩니다.

# 문서 상태와 저장 경고

- 문서에 실제 탭 문자나 0 너비 문자(U+2060)가 들어 있으면 저장 전 확인창을 띄울 수 있습니다.
- 각 경고는 환경설정 > 저장 옵션에서 켜고 끌 수 있습니다.
- U+2060은 화면에 보이지 않으므로 상태표시줄과 저장 경고를 함께 확인하는 것이 좋습니다.

# 툴팁 정렬

- D2R 인게임 툴팁은 보통 가운데 맞춤처럼 표시됩니다.
- 이 편집기는 작업 편의를 위해 기본값을 왼쪽 맞춤으로 두었습니다.
- 도구모음에서 왼쪽/가운데/오른쪽 맞춤을 바꿀 수 있습니다.
- 기본 맞춤값은 환경설정에서 바꿀 수 있습니다.

# 탭 정렬 작업

- 탭 구현/복원은 왼쪽 맞춤 또는 오른쪽 맞춤 작업을 전제로 합니다.
- 가운데 맞춤에서는 탭 기준 정렬이 의도대로 맞지 않을 수 있습니다.
- 게임 파일의 JSON 문자열 안에 실제 탭 문자를 그대로 넣으면 문제가 될 수 있습니다.
- 탭 정렬을 사용했다면 저장 경고와 문서 탭 표시를 함께 확인하는 것이 좋습니다.

# 색상 적용

- 색상을 적용할 글자를 편집창에서 선택한 뒤 도구모음의 색상칩을 누르면 해당 글자에 색상코드가 적용됩니다.
- 편집창 미리보기 색상도 함께 바뀌며, 코드창에서는 실제 `ÿcX` 색상코드 상태를 확인할 수 있습니다.
- 기본 색상 단축키는 [Ctrl]+[Alt]+색상 문자입니다.
- 예를 들어 초록색 코드가 `ÿc2`라면 [Ctrl]+[Alt]+[2]로 입력할 수 있습니다.
- **새 입력 시 기본 색** 옵션을 켜면 새로 타이핑하는 문자를 기본 색상으로 입력하려고 시도합니다.
- 이 옵션을 끄면 앞쪽 색상 흐름을 따라가는 쪽이 기본 동작입니다.

# Fn 색상 단축키

- 색상 버튼 위에 마우스를 올리고 [F1]~[F12]를 누르면 해당 색상에 Fn 단축키가 지정됩니다.
- 같은 버튼 위에서 같은 Fn키를 다시 누르면 지정이 해제됩니다.
- Fn 단축키가 지정된 색상은 기존 [Ctrl]+[Alt]+문자 단축키가 비활성화됩니다.
- Fn 지정을 해제하면 다시 문자 단축키로 돌아갑니다.
- Fn 지정 색상은 도구모음 맨 앞에 자동 배치되고 [F1] → [F12] 순서로 정렬됩니다.
- [Ctrl]을 누른 상태에서 일반 색상 버튼을 드래그하면 일반 색상 버튼 순서를 바꿀 수 있습니다.
- 환경설정 > 색상연결의 문자/Fn 지정 창에서 **기본값**은 해당 색상의 Fn 지정만 해제하고 문자 단축키로 되돌릴 때 사용합니다.

# 색상연결 초기화 참고

- D2R 패치나 개인 설정 변경으로 `ÿc` 색상코드와 실제 표시 색상의 연결이 다르게 느껴질 수 있습니다.
- 이미 환경설정에서 색상 연결을 저장했다면, 새 기본 색상값을 보려면 색상연결 초기화가 필요할 수 있습니다.

# 글꼴과 줄 간격

- 대표 글꼴, 글자 크기, 줄 간격을 조정할 수 있습니다.
- 기본값은 인게임 툴팁에 가깝게 보이도록 맞춰져 있습니다.
- 기본 제공 글꼴 외에도 Windows 시스템 글꼴과 직접 지정한 외부 폰트를 사용할 수 있습니다.
- 자주 쓰는 글꼴은 목록에서 즐겨찾기로 고정할 수 있습니다.

# 직접 경로 글꼴과 대체 글꼴

- 편집창 > 직접 경로 사용으로 대표 글꼴이나 대체 글꼴을 선택할 수 있습니다.
- 직접 경로로 선택한 폰트 파일은 프로그램 AppData 안의 폰트 캐시에 복사되고, 편집기는 그 사본을 사용합니다.
- 직접 경로 폰트를 새로 지정할 때는 원본 폰트 파일명 뒤에 날짜와 시각을 붙여 새 사본으로 저장합니다.
- 같은 파일명의 다른 폰트를 다시 골라도 이전 캐시가 계속 쓰이는 일을 피하기 위한 처리입니다.
- U+2060이 포함된 툴팁은 인게임에서 대표 글꼴 대신 대체 글꼴 쪽으로 출력될 수 있습니다.
- **U+2060 입력 시 대체 글꼴**이 켜져 있고 본문에 U+2060이 있으면 편집창도 환경설정에서 지정한 대체 글꼴로 표시합니다. 별도 지정이 없으면 내장 fallback 글꼴을 사용합니다.

# 복사와 붙여넣기

- [Ctrl]+[Z]: 실행취소
- [Ctrl]+[Y]: 다시 실행
- [Ctrl]+[X]: 잘라내기
- [Ctrl]+[C]: 복사
- [Ctrl]+[V]: 일반 붙여넣기
- [Ctrl]+[Shift]+[C]: 선택 영역 첫 글자의 글꼴 색상 복사
- [Ctrl]+[Shift]+[V]: 복사한 글꼴 색상을 선택 영역에 붙여넣기
- 글꼴 색상 복사는 편집창에서 블록 선택이 있을 때만 사용할 수 있으며, 우클릭 메뉴도 같은 조건에서 활성화됩니다.
- 일반 붙여넣기는 단축키 [Ctrl]+[V]로만 이용합니다.
- 텍스트로 붙여넣기는 우클릭 메뉴, 상단 편집 메뉴, 도구모음에서 사용할 수 있습니다.
- 우클릭 메뉴와 상단 편집 메뉴의 일반 붙여넣기 자리에는 안내용 비활성 항목이 표시됩니다.
- 편집창 복사 옵션에서 색상코드 포함 여부를 고를 수 있습니다.
- 줄바꿈을 실제 줄바꿈으로 복사할지 `\n` 기호로 복사할지도 선택할 수 있습니다.
- 유니코드는 글리프, escape, 제외 중 어떤 방식으로 복사할지 고를 수 있습니다.
- 색상 서식이 있는 외부 소스의 색상 근사 붙여넣기는 [Ctrl]+[V]에서만 시도합니다.
- 우클릭 메뉴, 상단 편집 메뉴, 도구모음의 텍스트 붙여넣기는 클립보드 권한창을 피하기 위해 텍스트만 읽습니다.
- 소스의 색상 구현 방식에 따라 완전히 동일하지 않을 수 있습니다.

# 텍스트 정리

- **텍스트 정리**는 지정한 항목만 정리합니다.
- 불필요한 공백류, 줄바꿈류, 탭 문자, 인코딩 문제를 일으킬 수 있는 문자 등을 선택적으로 정리할 수 있습니다.
- 레이아웃에 영향을 줄 수 있으므로, 정리 항목을 확인한 뒤 실행하는 것이 좋습니다.

# JSON 키 추출

- **JSON 키 추출**은 붙여넣은 JSON 코드에서 대상 언어 키값만 남기는 기능입니다.
- 기본 대상은 KoKR입니다.
- 환경설정에서 기본 대상 언어를 바꿀 수 있습니다.

# 찾기, 바꾸기, 이동

- [Ctrl]+[F]: 찾기
- [Ctrl]+[H]: 바꾸기
- [Ctrl]+[T]: 행 번호 찾아가기
- 찾기/바꾸기는 편집창과 코드창 대상을 나눠 지정할 수 있습니다.
- 와일드카드 `?`를 사용할 수 있습니다.
- 행 번호 찾아가기는 긴 문서에서 특정 줄을 빠르게 찾을 때 사용합니다.

# 색상변환과 유니코드 입력기

- [Ctrl]+[K]: 색상변환
- [Ctrl]+[G]: 유니코드 입력기
- 유니코드 입력기에서는 자주 쓰는 값을 관리할 수 있습니다.
- 즐겨찾기한 글리프는 오른쪽 클릭 메뉴에서도 바로 입력할 수 있습니다.

# 대용량 모드

- 다음 조건 중 하나에 해당하면 대용량 모드가 자동으로 켜집니다.
- 전체 문자 수 : 35,000자 이상 (코드창 기준)
- 실제 표시 문자 : 15,000자 이상 (색상코드 제외한 기준)
- 줄 수 : 1,000행 이상
- 대용량 모드에서는 입력 지연을 줄이기 위해 코드창 표시를 일시 중단하고, 편집창 내부 처리 범위를 현재 보고 있는 위치 주변 약 1,000행으로 제한합니다.
- 문서 전체 내용과 커서 위치는 내부 문서 모델에 그대로 유지됩니다. 스크롤하면 보고 있는 위치의 내용이 자동으로 표시되고, 본문을 클릭하면 그 위치로 커서를 옮길 수 있습니다.
- 코드창은 문서 크기가 줄거나 대용량 모드가 해제되면 다시 표시됩니다. 문서 저장과 편집 내용은 정상 처리됩니다.
- 대용량 모드에서는 일부 기능이 작동하지 않거나 불완전하게 작동할 수 있습니다.
- 대용량 모드에서는 행번호와 커서 안정성을 위해 편집창과 코드창 자동 줄바꿈을 임시로 끕니다.
- 행번호는 논리 행 기준으로 표시됩니다.
- 색상 오버레이는 정밀 색상 미리보기보다 클릭과 caret 안정성을 우선해 간소화됩니다.
- 대용량 문서에서도 현재 화면 주변 줄만 색상 overlay로 그려 색상 표시를 항상 유지합니다. 별도의 색상 표시 ON/OFF 옵션은 사용하지 않습니다.

# 상태표시줄

- 상태표시줄에서는 현재 모드, 문서 크기, 커서 위치, 작업 메시지를 확인할 수 있습니다.
- 주의나 오류가 있을 때도 상태표시줄에 관련 메시지가 표시됩니다.
- 문서가 커지거나 보이지 않는 문자가 포함된 경우 상태표시줄을 함께 확인하는 것이 좋습니다.

# Language

- 메뉴바의 **정보** 오른쪽에 있는 **Language** 메뉴에서 **English**와 **한국어**를 전환할 수 있습니다.
- 새 설정의 기본 언어는 한국어입니다.
- 선택한 언어는 즉시 적용되며 다음 실행에도 유지됩니다.
- `Korean.lng`와 `English.lng`는 실행 파일에 함께 포함됩니다.

# 환경설정

- 데이모드와 다크모드를 지원합니다.
- 기본값은 다크모드입니다.
- 환경설정에서 다음 실행 시작 테마를 바꿀 수 있습니다.
- 편집창과 코드창 색상도 조정할 수 있습니다.
- 저장 옵션, 표시 설정 저장, 기본 맞춤값, 기본 대상 언어, 색상연결 등 주요 동작을 환경설정에서 바꿀 수 있습니다.

# 사용자 데이터 정리

- 포터블 배포판이라도 사용자 데이터가 남을 수 있습니다.
- 환경설정, 최근 파일 목록, 검색기록, 사용자 색상 연결, 사용자 지정 폰트 캐시, AppData/LocalAppData 하위 폴더 등이 해당됩니다.
- 환경설정 > 일반 > **프로그램이 만든 사용자 데이터 삭제..**는 프로그램 사용을 끝낼 때 앱이 만든 사용자 데이터를 정리하고 종료하는 기능입니다.
- 이 기능은 실행 파일, 사용자가 편집한 txt 문서, 사용자 원본 폰트 파일은 삭제하지 않습니다.

# 개발자모드

- 개발자모드는 버전 정보 창의 **개발자 모드** 체크박스로 켜고 끕니다.
- 별도 확인창 없이 체크 상태가 즉시 반영됩니다.
- 개발자모드는 프로그램 종료 시까지만 유지됩니다.
- 일반모드에서는 [F12]가 개발자도구를 열지 않고 색상 Fn 단축키로 동작할 수 있습니다.
- 개발자모드에서는 [F12]가 개발자도구 호출 단축키로 바뀝니다.
- 이때 F12 색상 Fn 설정값은 지우지 않고, 실행 중에만 임시 비활성화됩니다.

# 개발자 전용 참고

- 이 항목은 일반 사용법이 아니라 빌드 소스를 관리할 때 참고하는 내용입니다.
- D2R 패치로 `ÿc` 색상코드와 실제 표시 색상의 연결이 바뀌면, 빌드 소스의 `app/src/colorPalette.js` 안 `DEFAULT_COLOR_PALETTE`와 `DEFAULT_COLOR_CODE`를 확인해야 합니다. 빌드소스 별도 참고.
- `DEFAULT_COLOR_PALETTE`의 `code`는 D2R 색상코드, `hex`는 편집기 표시 색상, `name`/`memo`는 UI 표시용 설명입니다. 빌드소스 별도 참고.
- 이미 사용자가 환경설정에서 색상 연결을 저장했다면 새 시스템 초기값을 보려면 색상 연결 초기화가 필요할 수 있습니다.
- 패널 layout JSON의 일부 `FocusableWidget`에는 개별 `tooltipStyle`/`fontStyle`을 지정할 수 있습니다. 빌드소스 별도 참고.
- `newlineHandling`을 `standard`로 바꾸면 문자열의 줄 구조가 더 직접적으로 반영되어 왼쪽 정렬형 툴팁처럼 구성할 수 있습니다. 빌드소스 별도 참고.
